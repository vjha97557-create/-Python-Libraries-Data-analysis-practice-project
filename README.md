# Python libraries Data Analysis Practice 🐼

## 📌 About This Repository

This repository contains my hands-on practice of Python libraries used in Data Analytics, with a primary focus on Pandas, NumPy, Matplotlib, and Seaborn.

The notebook covers different techniques for exploring, cleaning, manipulating, transforming, and visualizing datasets.

I have practised these concepts using multiple datasets, including Titanic, Wine Quality, HR, Tips, Amazon Fires, and Bengaluru House Data.

The main objective is to develop practical data analysis skills and understand how Python libraries are used to work with real-world datasets.

## 🎯 Topics Covered

### 1. Pandas

* Creating and working with Series and DataFrames.
* Reading CSV files using `read_csv()`.
* Exploring datasets using `head()`, `tail()`, `info()`, and `describe()`.
* Selecting rows and columns using `loc[]` and `iloc[]`.
* Identifying and handling missing values.
* Detecting and removing duplicate records.
* Data type conversion.
* String manipulation.
* Grouping and aggregation using `groupby()`.
* Statistical operations: Mean, Median, and Mode.
* Working with dates using `date_range()`.

### 2. NumPy

* Creating numerical arrays.
* Using `arange()`.
* Performing basic mathematical operations.

### 3. Matplotlib

* Line plots.
* Pie charts.
* Histograms.
* Scatter plots.
* Subplots.
* Customizing charts with labels, titles, markers, and legends.

### 4. Seaborn

* Distribution plots.
* Histograms.
* Jointplots.
* Pairplots.
* Countplots.
* Barplots.
* Boxplots.
* Scatterplots.
* Violinplots.
* Heatmaps.
* Regression plots.

### 5. Statistical Analysis

* Descriptive statistics.
* Group-wise analysis.
* Correlation analysis.
* Outlier detection using the IQR method.
